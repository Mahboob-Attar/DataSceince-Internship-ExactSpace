# 📌 Internship Project – Dual Tasks (Data Science + NLP)

This repository contains **two completely independent tasks** completed as part of an internship project.  
The project demonstrates applied AI/ML skills across **industrial time-series data analysis** and **LLM-based information retrieval**.

---

## ⚠️ Important Note

Task 1 (Machine Data Analysis) and Task 2 (RAG + LLM) are **completely separate**:

- **Task 1** → Time-series sensor analysis, including **data cleaning, shutdown detection, clustering, anomalies, and forecasting**.  
- **Task 2** → Retrieval-Augmented Generation (RAG) system for **querying technical PDF documents** using **vector embeddings and open-source LLMs**.  

There is **no direct dependency** between the two tasks.  

Together, the project showcases **end-to-end applied AI skills** in **Data Science, Machine Learning, and NLP/LLM system design**.

---

## 🏭 Task 1: Machine Data Analysis

Task 1 involves **three years of cyclone machine sensor data** (~370,000 records at 5-minute intervals).  
The focus is on **data preparation, cleaning, and analysis** to understand machine behavior, detect shutdowns and anomalies, and perform short-term forecasting.  

Full details, outputs, and code are available in the `Task1/` folder.

---

## 🤖 Task 2: Retrieval-Augmented Generation (RAG) + LLM

Task 2 involves **building a RAG system** to allow natural language querying of multiple technical PDF documents (manuals, SOPs, troubleshooting guides).  
The system uses **document embeddings, vector retrieval, and LLM-based answer generation** with guardrails for reliability.  

Full details, prototypes, and code are available in the `Task2/` folder.

---

## ✅ Final Takeaway

This internship project demonstrates **two complementary AI/ML capabilities**:

- Task 1 → Industrial **time-series data analysis and machine learning modeling**  
- Task 2 → **RAG + LLM system design** for document-based Q&A  

Together, they showcase the ability to handle both **data-heavy ML tasks** and **advanced NLP/LLM system development**, providing a **full-stack applied AI experience**.
